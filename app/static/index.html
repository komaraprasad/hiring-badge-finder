Add the extension to your browser

This tool reads LinkedIn only through your own browser, using a small extension.

  1. Open chrome://extensions (or edge://extensions) and turn on Developer mode.
  2. Click Load unpacked and choose the extension folder inside the Hiring Badge Finder project folder (the folder that has run.bat). Later updates then only need Reload.
  3. Click Download below and extract the zip. Click Load unpacked and choose the extracted folder. Use this download only: a copy from anywhere else will not connect to this dashboard.
  4. Come back to this page and refresh it.

Other computer without the project folder? Use Download and load the extracted folder instead.
